# Sigma Hellas Technical Wiki

Εσωτερικό, στατικό Technical Wiki για τις διαδικασίες και το troubleshooting του τεχνικού τμήματος της Sigma Hellas.

## Χρήση

Ανοίξτε το `index.html` σε browser. Δεν απαιτείται build ή εξωτερική εξάρτηση.

Οι εικόνες βρίσκονται στον φάκελο `assets/images/`, ώστε το project να λειτουργεί σωστά και όταν φιλοξενείται από GitHub Pages ή άλλο static host.

## Περιεχόμενο

- Έλεγχος προβληματικού μελανιού
- Παραλαβή μη λειτουργικού μελανιού
- Reiner 970 — Transmission Error / Internal error -5
- TSC — σύνδεση μέσω δικτύου και σταθερή IP
- Εγκατάσταση προγράμματος TSC
- Reiner 1025 — μπλοκάρισμα μηχανισμού μελανιού
